# Demo — Simulador didáctico Vehículo Híbrido Enchufable (PHEV)

Demo pública de exhibición. Interfaz interactiva con los flujos de energía
del vehículo en 5 modos: Eléctrico, Híbrido, Térmico, Recarga y Frenado
regenerativo.

> Este repositorio solo contiene el build publicado. El código fuente y su
> desarrollo son privados.
